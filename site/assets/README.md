# site/assets

Historical images used by the deep-dive page. They're public domain but not
committed here — run `./fetch.sh` to pull them from Wikimedia Commons.

| File | Credit | Status |
|---|---|---|
| `cottingley.jpg` | *Frances and the Fairies*, Elsie Wright, 1917 | Public domain (published 1917) |

If a file is absent the page renders the figure as a caption-only block, so
nothing breaks.
